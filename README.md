# Conversor MP4 para MP3

Conversor em português para vários vídeos MP4, com download individual de MP3 ou de todos os áudios em ZIP.

## Usar

Abra `index.html` no Chrome ou Edge atualizado. A conversão acontece no navegador; vídeos não são enviados a um servidor. É necessária internet para carregar lamejs e JSZip. A compatibilidade depende do codec de áudio do vídeo e da memória disponível.

## Publicar no Netlify

Importe este repositório no Netlify. Deixe o comando de build vazio e use `.` como diretório de publicação. O arquivo `netlify.toml` já configura o diretório.

## Validação

A sintaxe JavaScript foi verificada. A conversão completa ainda precisa ser testada em um navegador com conexão à internet.
